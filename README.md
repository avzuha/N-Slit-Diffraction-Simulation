# 🔬 N-Slit Diffraction Pattern Simulation

A Python script to simulate and visualize the diffraction pattern for **n slits** using numerical methods.

## 📌 Features
- Input number of slits, wavelength, slit width, and slit separation.
- Computes intensity distribution using physics formulas.
- Plots normalized diffraction pattern with `matplotlib`.
